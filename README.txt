РАСЧЁТ БАРАБАНОВ — КОМПЛЕКТ ДЛЯ GITHUB PAGES

В архиве — версия приложения v17 и значки вкладки браузера и экрана «Домой» на iPhone.

1. Распакуйте архив.
2. Загрузите все файлы из архива в одну и ту же папку репозитория, где находится index.html. При обновлении существующего сайта замените прежний index.html и совпадающие файлы значков.
3. В GitHub откройте Settings → Pages и убедитесь, что публикация настроена на нужную ветку и папку. Откройте адрес сайта после завершения публикации.
4. На iPhone откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой».

Браузеры могут сохранять старую иконку в кэше. Если она не обновилась, обновите страницу, очистите кэш или удалите старый ярлык и добавьте его заново.

Файлы favicon-32x32.svg и favicon-32x32.png сохранены из исходных изображений. Ссылки в index.html уже добавлены. Фон и инструкция встроены в HTML. Для работы некоторых возможностей приложения может требоваться подключение к интернету.
