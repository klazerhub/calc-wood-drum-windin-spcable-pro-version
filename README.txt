Готовый index.html уже связан со всеми иконками. Вставлять код вручную не нужно.
Основа: последний файл index(4).html. Расчёты, фон и встроенная инструкция сохранены.

ПУБЛИКАЦИЯ
1. Распакуйте ZIP на компьютере.
2. Откройте свой репозиторий GitHub и папку, из которой публикуется сайт.
3. Add file → Upload files: загрузите СОДЕРЖИМОЕ архива в эту папку, заменив совпадающие файлы. Не загружайте сам ZIP и не создавайте дополнительную вложенную папку.
4. Нажмите Commit changes. Дождитесь окончания публикации GitHub Pages.
5. Откройте действующий адрес сайта. Все пути относительные: они рассчитаны и на сайт в подпапке /имя-репозитория/.

ЗНАЧКИ
favicon.svg, PNG 16/32/48 и favicon.ico — вкладки и закладки.
apple-touch-icon.png — экран «Домой» на iPhone/iPad.
android-chrome-192x192.png и 512x512 — обычные значки Android.
android-maskable-192x192.png и 512x512 — адаптивные значки Android с безопасными полями для системной обрезки.
site.webmanifest — описание названия, значков и запуска с экрана «Домой».
SVG 16/32 и apple-touch-icon.svg — векторные исходники, пригодные для редактирования; для iPhone подключён PNG.

В исходном файле Apple значок был маленьким и смещённым. Здесь он увеличен и отцентрирован по векторному оригиналу; серый фон непрозрачный.

НА ТЕЛЕФОНЕ
На iPhone: Safari → Поделиться → На экран «Домой».
На Android: откройте меню браузера и выберите доступную команду добавления на главный экран или установки. Название команды зависит от браузера.

ОБНОВЛЕНИЕ СТАРОЙ ИКОНКИ
Для подключений задана новая версия ?v=20261027b. Старые закладки и ярлыки всё равно могут хранить иконку в кэше: удалите старый ярлык/закладку и добавьте заново. При необходимости обновите кэш браузера.
История расчётов хранится в браузере. Не удаляйте данные сайта ради обновления иконки без необходимости.

ПРОВЕРКА
Проверены размеры PNG, непрозрачность мобильных значков, состав ICO, ссылки HTML/manifest и целостность архива. На физических телефонах комплект не тестировался. Вид значка и возможность установки зависят от браузера и ОС. Манифест не добавляет автономную работу без интернета.
