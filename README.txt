РАСЧЁТ БАРАБАНОВ v18 — 28.10.2026

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Распакуйте архив.
2. Загрузите его содержимое в прежнюю папку сайта, заменив index.html, значки и site.webmanifest. Не загружайте сам ZIP вместо файлов и не добавляйте лишнюю вложенную папку.
3. Сохраните изменения через Commit changes и дождитесь завершения публикации.
4. Откройте действующий адрес сайта. Все подключения уже внесены в HTML, вставлять код вручную не нужно.

СОСТАВ
index.html — приложение со встроенным фоном, инструкцией, справочником ГОСТ и 3D.
favicon.ico, favicon.svg и PNG/SVG 16/32/48 — значки вкладки и закладок.
apple-touch-icon.png — новая приложенная иконка экрана «Домой» iPhone/iPad, 180×180, непрозрачная.
android-chrome-192x192.png / 512x512 и android-maskable-192x192.png / 512x512 — обычные и адаптивные значки Android.
site.webmanifest — название, значки и запуск с экрана «Домой».
docs/ — обновлённая проектная документация, ТЗ Word 1.1 и протокол проверок v18.
tests/verify.cjs — воспроизводимая проверка арифметики и распределения; запуск через установленный Node.js: node tests/verify.cjs. Установка дополнительных пакетов не требуется.

ОБНОВЛЕНИЕ
Публикуйте по прежнему адресу: история и настройки привязаны к браузеру и пути сайта. Не очищайте данные сайта ради обновления иконки. Старые ярлыки могут сохранять значок: удалите старый ярлык и добавьте его заново после обновления.
На iPhone: Safari → Поделиться → На экран «Домой».
На Android: меню браузера → На главный экран / Установить (название зависит от браузера).

ИЗМЕНЕНИЯ
Точная вместимость без потери метра; до 99 заданных длин; прокрутка результата при >10 барабанах; предупреждение и запрет сохранения при >300; безопасное подтверждение после РБ-9999. Инструкция обновлена, включая новые иллюстрации. Исправлена обработка сенсорного сброса 3D после вращения.

ПРОВЕРКА
Автоматические проверки выполнены. Физические iPhone/Android не были доступны: перед вводом в эксплуатацию проверьте на ваших устройствах открытие сайта и инструкции, вращение 3D, сохранение истории и добавление ярлыка.

ВОЗВРАТ К ПРЕЖНЕЙ ВЕРСИИ
Перед заменой сохраните текущий комплект файлов репозитория. При необходимости верните предыдущие файлы через историю GitHub, сохранив адрес сайта. Историю браузера не удаляйте. Старые версии приложения могут не поддерживать новые записи с количеством длин больше 16.
